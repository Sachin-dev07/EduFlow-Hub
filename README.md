# EduFlow Hub

Educational management platform built with MERN stack.

## Features

- User authentication (Teachers, Students, Parents)
- Course management
- Assignment submission and grading
- Grade tracking
- Messaging system

## Setup

```bash
npm install
cd backend && npm install
cp backend/.env.example backend/.env
```

Edit `backend/.env` with your MongoDB URI and JWT secret.

## Run

```bash
npm run dev        # Frontend
npm run backend    # Backend
```

## Tech Stack

React • TypeScript • Node.js • Express • MongoDB • Tailwind CSS
